# اليمان — مشروع أندرويد (مع الفتح بالبصمة)

- واجهة البرنامج: مجلد www (نفس برنامجك مع إضافة البصمة).
- الأندرويد: مجلد android (Capacitor 7، الحد الأدنى أندرويد 6، الهدف 15).
- جسر الحفظ والطباعة: android/app/src/main/java/com/alyaman/invoice2/AlyPrint.java (مُعاد كتابته).
- البناء التلقائي: .github/workflows/build-apk.yml — عند الرفع إلى GitHub يُبنى APK ويظهر في Actions > Build APK > Artifacts > alyaman-apk.

## التوقيع
مفتاح التوقيع الجديد: android/app/alyaman-release.jks (الاسم المستعار alyaman، كلمة المرور في android/app/build.gradle).
احتفظ بنسخة منه خارج GitHub؛ ضياعه يعني ألا تتحدّث التطبيق مستقبلًا فوق النسخة المثبتة. ارفع المشروع إلى مستودع **خاص** فقط.

## التثبيت فوق النسخة القديمة
النسخة القديمة موقّعة بمفتاح مختلف، فلا تتحدّث فوقها: صدّر نسخة احتياطية من البرنامج القديم أولًا ثم احذفه وثبّت الجديد واستعد البيانات.
